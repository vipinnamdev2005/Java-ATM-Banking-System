#  Java ATM Banking System

A console-based ATM Banking System developed using Java. This project allows users to perform basic banking operations such as checking balance, depositing money, withdrawing money, and transferring money between accounts.

##  Project Overview

This project simulates basic ATM operations through a console-based menu. It uses Java classes, objects, constructors, ArrayList, methods, and conditional statements to manage accounts and transactions.

##  Features

- Account ID and PIN verification.
- Check account balance.
- Withdraw money.
- Deposit money.
- Transfer money between accounts.
- Search accounts using Account ID.
- Prevent withdrawal when funds are insufficient.
- Prevent invalid amounts.
- Prevent transferring money to the same account.
- Menu-driven interface.

##  Technologies Used

- Java
- ArrayList
- Scanner
- Classes and Objects
- Constructors
- Methods
- Switch Statements
- Loops
- Conditional Statements

##  How to Run

1. Clone this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java file.
4. Run the program.

### Compile

```bash
javac atm.java
```

### Run

```bash
java atm
```

##  Available Operations

### 1. Check Balance
Displays the current account balance after account verification.

### 2. Withdraw
Withdraws money from the account if the balance is sufficient.

### 3. Deposit
Adds money to the existing account balance.

### 4. Transfer
Transfers money from one account to another after validating the accounts and available balance.

### 5. Exit
Exits the ATM program.

##  Disclaimer

This is a beginner-level educational project. It is not a real banking system. Account data is stored temporarily in memory and is not saved permanently. PIN security and transaction handling are not designed for real banking use.
